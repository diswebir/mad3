# سامانه مدیریت مدرسه (Node.js)

سامانه‌ای جامع، سبک و ماژولار برای مدیریت مدرسه با **ویزارد نصب**، قابل نصب روی **هاست cPanel**، با رابط فارسی راست‌به‌چپ و فونت **وزیرمتن** در کل سیستم.

مدیر مدرسه معلم‌ها را اضافه می‌کند، برای هر معلم کلاس (راهنما + دروس) تعیین می‌کند، دانش‌آموزان را در کلاس‌ها ثبت می‌کند و هر دانش‌آموز **پنل کاربری و پرونده کامل** (اطلاعات هویتی، اولیا، تماس‌ها، سلامت، مدارک، حضور و غیاب، نمرات، ...) دارد. **حضور و غیاب** توسط معلم ثبت می‌شود و **ارتباط دانش‌آموز، معلم و مدیر از طریق تیکت** انجام می‌شود (از جمله توجیه غیبت که با تأیید معلم/مدیر مستقیم در حضور و غیاب اعمال می‌شود).

> **نسخه‌ی ۲.۰.۰** — بیش از **۱۴۰ قابلیت** در نسخه‌ی ۱ و ۱۴ بستر تازه در نسخه‌ی ۲ (پایان سال، پنل اولیا، پیامک IPPanel، مالی اقساطی، QR، زمان‌بندی، منابع انسانی و …). فهرست کامل: [docs/FEATURES.md](docs/FEATURES.md) — تغییرات: [docs/CHANGELOG.md](docs/CHANGELOG.md)

## شروع سریع (محلی)

```bash
npm install
npm start            # http://localhost:3000  → ویزارد نصب
```

در اولین اجرا ویزارد نصب باز می‌شود. گزینه «نصب داده نمونه» را بزنید تا سامانه خالی نباشد:

| نقش | نام کاربری | رمز |
|---|---|---|
| مدیر | همان که در ویزارد ساختید | همان |
| معاون | `deputy` | `deputy123` |
| معلم (راهنمای هفتم الف) | `t.ahmadi` | `teacher123` |
| دانش‌آموز | `14050001` | `student123` |

نصب بدون مرورگر (خط فرمان): `npm run demo` (مدیر: `admin` / `Admin#12345`؛ و با `--no-demo` برای نصب خالی).

## نصب روی cPanel
**نصب بدون SSH (با تصویر، با دمو و بدون دمو): [docs/INSTALL-NO-SSH.md](docs/INSTALL-NO-SSH.md).** راهنمای کامل و گام‌به‌گام (نصب واقعی، **نصب دمو**، رفتن از دمو به واقعی، سایت دموی عمومی، cron، پیامک، به‌روزرسانی و عیب‌یابی): [docs/CPANEL.md](docs/CPANEL.md) — خلاصه: آپلود ← Setup Node.js App (فایل شروع `app.js`) ← Run NPM Install ← ساخت دیتابیس MySQL ← باز کردن آدرس و تکمیل ویزارد.

## نقش‌ها
| نقش | توانایی |
|---|---|
| **مدیر** | همه‌چیز: کاربران، تنظیمات، ماژول‌ها، معلمان، کلاس‌ها، دانش‌آموزان، مالی، پشتیبان‌گیری، گزارش فعالیت |
| **معاون** | مانند مدیر، به‌جز کاربران، تنظیمات، ماژول‌ها، پشتیبان‌گیری و گزارش فعالیت |
| **معلم** | فقط کلاس‌های خودش: حضور و غیاب، نمرات، تکالیف، تیکت، اطلاعیه کلاس، انضباطی، جلسات اولیا |
| **اولیا** | حساب جدا با شماره‌ی همراه؛ نمای فقط‌خواندنیِ فرزند (یا فرزندان) خود |
| **دانش‌آموز** | فقط اطلاعات خودش: پرونده، حضور و غیاب، کارنامه (نمرات منتشرشده)، تکالیف، تیکت، برنامه، مالی |

## ماژول‌ها
هسته (دانش‌آموزان، معلمان، کلاس‌ها و دروس، تنظیمات) همیشه فعال است. ۲۴ ماژول دیگر از **تنظیمات ← ماژول‌ها** قابل روشن/خاموش‌اند: اولیا، پیامک، پایان سال تحصیلی، برگه‌ی خروج، بانک سؤال، منابع انسانی، حضور و غیاب، برنامه هفتگی، نمرات و کارنامه، تکالیف، برنامه امتحانات، انضباطی، تیکت، اطلاعیه‌ها، تقویم، جلسات اولیا، مدارک پرونده، بهداشت، مالی، کتابخانه، سرویس مدرسه، گزارش‌ها، گزارش فعالیت‌ها، پشتیبان‌گیری. با خاموش‌شدن یک ماژول، منو، مسیرها، ویجت داشبورد و تب مربوط در پرونده حذف می‌شود (داده‌ها حفظ می‌شوند).

برای افزودن ماژول جدید: یک ورودی در `src/modules.js`، یک روتر در `src/routes/` (با `modules.guard('key')`) یا یک تعریف ساده در `src/resources.js` (موتور CRUD عمومی).

## ساختار پروژه
```
app.js                 نقطه ورود (Passenger / cPanel)
src/server.js          ساخت اپلیکیشن، ویزارد یا اپلیکیشن اصلی
src/installer/         ویزارد نصب
src/schema.js          ساختار پایگاه داده (Knex؛ SQLite و MySQL)
src/seed.js            داده پایه و داده نمونه
src/modules.js         ثبت ماژول‌ها و منو
src/crud.js            موتور CRUD عمومی (لیست، فرم، حذف، CSV)
src/resources.js       منابع ساده روی موتور CRUD
src/routes/            مسیرهای هر ماژول
src/lib/gradesCalc.js  محاسبه میانگین، معدل و رتبه
views/                 قالب‌های EJS
public/                CSS، JS، فونت وزیرمتن
data/                  تنظیمات، SQLite، فایل‌های بارگذاری‌شده (خارج از Git)
docs/                  امکانات و راهنمای cPanel
test/smoke.test.js     تست یکپارچه (نصب، نقش‌ها، سناریوها)
```

## پیکربندی
تنظیمات نصب در `data/config.json` ذخیره می‌شود؛ متغیرهای محیطی (`DB_*`, `BASE_PATH`, `SESSION_SECRET`, `SCHOOL_DATA_DIR`, `SECURE_COOKIES`) اولویت دارند. جزئیات در [docs/CPANEL.md](docs/CPANEL.md).

بازنشانی رمز یک کاربر از خط فرمان: `node scripts/reset-admin.js <username> <password>`

## تست
```bash
npm test                          # همه‌ی آزمون‌ها: دود + نسخه‌ی ۲ (واحد، یکپارچه، پایان سال)
npm run test:smoke                # فقط آزمون دود (نصب با ویزارد، ورود با هر نقش، بازدید صفحات)
npm run test:v2                   # فقط آزمون‌های نسخه‌ی ۲
TEST_BASE_PATH=/school npm test   # همان تست برای نصب در زیرپوشه (شبیه cPanel)
```
تست روی SQLite اجرا می‌شود. مسیر MySQL از همان کدهای Knex استفاده می‌کند ولی در محیط توسعه این پروژه با یک سرور MySQL واقعی اجرا نشده است؛ پیش از استفاده عملی یک‌بار نصب آزمایشی با MySQL انجام دهید.

## نکات فنی
- **بدون وابستگی کامپایلی اجباری**: bcryptjs و mysql2 خالص JavaScript‌اند. `better-sqlite3` اختیاری است و اگر روی هاست نصب نشود، MySQL استفاده می‌شود.
- تاریخ‌ها به‌صورت میلادی ذخیره و به‌صورت شمسی نمایش/دریافت می‌شوند؛ زمان‌ها UTC ذخیره و به وقت تهران نمایش داده می‌شوند.
- فایل‌های بارگذاری‌شده خارج از پوشه عمومی هستند و فقط با بررسی دسترسی قابل دانلودند.
