# راهنمای نصب روی هاست cPanel

این راهنما برای هاست‌هایی است که ابزار **Setup Node.js App** (CloudLinux Node.js Selector / Phusion Passenger) دارند.

## پیش‌نیازها
- Node.js نسخه ۱۸ یا بالاتر (۲۰ یا ۲۲ پیشنهاد می‌شود)
- یک پایگاه داده MySQL/MariaDB (پیشنهادی) — یا SQLite در صورتی که `better-sqlite3` روی هاست نصب شود
- حداقل ۲۵۶ مگابایت حافظه برای برنامه

## مرحله ۱: آپلود فایل‌ها
1. پروژه را (بدون پوشه `node_modules`) فشرده و از طریق **File Manager** یا FTP در مسیری **بیرون از `public_html`** آپلود و استخراج کنید، مثلاً `/home/USER/school`.
2. پوشه `data` باید توسط کاربر هاست قابل نوشتن باشد (در حالت عادی هست). تنظیمات، فایل‌های بارگذاری‌شده و در صورت استفاده از SQLite پایگاه داده در همین پوشه نگهداری می‌شوند.

## مرحله ۲: ساخت پایگاه داده (برای MySQL)
1. در cPanel بخش **MySQL® Databases** را باز کنید.
2. یک پایگاه داده بسازید (مثلاً `USER_school`) و یک کاربر جدید با رمز قوی بسازید.
3. کاربر را به پایگاه داده اضافه کنید و **ALL PRIVILEGES** بدهید.
4. نام پایگاه داده، نام کاربری و رمز را یادداشت کنید (در ویزارد وارد می‌شود).

## مرحله ۳: ساخت اپلیکیشن Node.js
1. cPanel ← **Setup Node.js App** ← **Create Application**
2. تنظیمات:
   - **Node.js version**: ۲۰ یا بالاتر
   - **Application mode**: Production
   - **Application root**: `school` (مسیر آپلود)
   - **Application URL**: دامنه یا زیردامنه (یا یک زیرپوشه مثل `example.com/school`)
   - **Application startup file**: `app.js`
3. **Create** بزنید، سپس روی **Run NPM Install** کلیک کنید تا وابستگی‌ها نصب شوند.
   - اگر `better-sqlite3` نصب نشد (به‌دلیل نبود دسترسی شبکه/کامپایلر) مشکلی نیست؛ MySQL را در ویزارد انتخاب کنید.
4. در صورت نیاز در بخش Environment variables مقادیر زیر را اضافه کنید (همگی اختیاری‌اند):

| متغیر | توضیح |
|---|---|
| `BASE_PATH` | مسیر زیرپوشه (مثلاً `/school`). معمولاً از `PASSENGER_BASE_URI` خودکار تشخیص داده می‌شود. |
| `SESSION_SECRET` | کلید نشست؛ اگر نگذارید ویزارد یک کلید تصادفی می‌سازد. |
| `SECURE_COOKIES` | `true` برای اجبار کوکی امن (در صورت HTTPS بودن در نصب خودکار فعال می‌شود). |
| `SCHOOL_DATA_DIR` | مسیر دیگر برای پوشه data (مثلاً خارج از ریشه اپلیکیشن). |
| `DB_CLIENT`, `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` | تنظیم پایگاه داده از طریق محیط (اولویت بالاتر از ویزارد). |

5. **Restart** بزنید.

## مرحله ۴: ویزارد نصب
نشانی اپلیکیشن را در مرورگر باز کنید؛ ویزارد نصب نمایش داده می‌شود:
1. بررسی پیش‌نیازها
2. پایگاه داده (MySQL ← مشخصات مرحله ۲ و «آزمایش اتصال»؛ یا SQLite)
3. اطلاعات مدرسه
4. حساب مدیر (رمز حداقل ۸ نویسه)
5. انتخاب ماژول‌ها و داده نمونه
6. شروع نصب

> ⚠️ پس از ایجاد اپلیکیشن، ویزارد را همان لحظه کامل کنید. تا پایان نصب هر بازدیدکننده‌ای می‌تواند ویزارد را ببیند.

## بروزرسانی
1. فایل‌های جدید را روی قبلی کپی کنید (**پوشه `data` را حذف/جایگزین نکنید**).
2. **Run NPM Install** و سپس **Restart**.
3. جدول‌های جدید (در صورت وجود) هنگام راه‌اندازی خودکار ساخته می‌شوند.

## پشتیبان‌گیری
- از منوی **پشتیبان‌گیری** در سامانه خروجی JSON بگیرید (یا فایل SQLite).
- پوشه `data/uploads` (عکس‌ها و مدارک) را جداگانه کپی کنید.
- برای MySQL می‌توانید از **Backup Wizard** خود cPanel هم استفاده کنید.

## عیب‌یابی
| نشانه | راه‌حل |
|---|---|
| صفحه خطای Passenger / 503 | فایل `stderr.log` در پوشه اپلیکیشن یا Errors در cPanel را ببینید؛ نسخه Node و اجرای NPM Install را بررسی کنید. |
| ویزارد می‌گوید «دسترسی نوشتن ندارد» | مجوز پوشه `data` را به `755` (یا `775`) تغییر دهید. |
| نمی‌توان SQLite را انتخاب کرد | درایور نصب نشده است؛ MySQL را استفاده کنید. |
| استایل/فونت بارگذاری نمی‌شود در زیرپوشه | متغیر `BASE_PATH` را با همان مسیر Application URL تنظیم کنید و Restart بزنید. |
| پس از ورود دوباره به صفحه ورود برمی‌گردد | ساعت سرور/کوکی امن را بررسی کنید؛ اگر پشت HTTPS نیستید `SECURE_COOKIES` را حذف کنید. |
| فراموشی رمز مدیر | با ابزار phpMyAdmin رمز را نمی‌توان مستقیم عوض کرد؛ یک مدیر دیگر از «کاربران» رمز را بازنشانی کند، یا از خط فرمان اسکریپت زیر را اجرا کنید: `node scripts/reset-admin.js نام‌کاربری رمز‌جدید` |
