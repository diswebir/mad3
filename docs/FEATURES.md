# فهرست امکانات (مرحله اول)

همه موارد زیر در کد پیاده‌سازی شده و بخش عمده‌ای از آن‌ها با تست خودکار (`npm test`) بررسی می‌شوند.
ماژول‌های غیرپایه از صفحه «ماژول‌ها» (فقط مدیر) قابل روشن/خاموش‌اند.

## ۱. نصب و راه‌اندازی
1. ویزارد نصب شش‌مرحله‌ای (پیش‌نیازها ← پایگاه داده ← مدرسه ← مدیر ← ماژول‌ها ← نصب)
2. بررسی خودکار پیش‌نیازهای سرور (نسخه Node، دسترسی نوشتن، درایورها)
3. انتخاب پایگاه داده: MySQL/MariaDB (پیشنهاد cPanel) یا SQLite (بدون تنظیمات)
4. دکمه «آزمایش اتصال» پایگاه داده پیش از نصب
5. ساخت خودکار جدول‌ها، ایندکس‌ها و تنظیمات اولیه
6. نصب اختیاری داده نمونه (دمو): ۱۴ معلم، ۶ کلاس، ۷۲ دانش‌آموز با حضور و غیاب، نمرات، تیکت، مالی و ...
7. پاک‌سازی خودکار نصب ناقص (امکان تلاش دوباره)
8. غیرفعال‌شدن ویزارد پس از نصب (قفل نصب)
9. سازگاری با cPanel (Setup Node.js App / Passenger) و نصب در زیرپوشه (`BASE_PATH` / `PASSENGER_BASE_URI`)
10. نصب بدون مرورگر با `npm run demo` (خط فرمان)
11. ایجاد خودکار جدول‌های جدید هنگام بروزرسانی نسخه

## ۲. احراز هویت، نقش‌ها و امنیت
12. چهار نقش: مدیر، معاون، معلم، دانش‌آموز (هر کدام پنل جداگانه)
13. ورود با نام کاربری و رمز عبور، خروج امن
14. ذخیره نشست‌ها در پایگاه داده (مناسب هاست اشتراکی) و پاک‌سازی خودکار نشست‌های منقضی
15. رمزنگاری رمزها با bcrypt
16. محافظت CSRF برای همه فرم‌ها (حتی فرم‌های بارگذاری فایل)
17. قفل موقت ورود پس از چند تلاش ناموفق (قابل تنظیم)
18. تغییر اجباری رمز اولیه در اولین ورود
19. سیاست حداقل طول رمز (قابل تنظیم)
20. هدرهای امنیتی (Helmet) و CSP بدون اسکریپت درون‌خطی
21. دسترسی نقش‌محور و سطح‌ردیف: معلم فقط کلاس‌های خودش، دانش‌آموز فقط پرونده خودش
22. بارگذاری امن فایل: فهرست پسوند مجاز، محدودیت حجم، نام تصادفی، دانلود فقط با مجوز
23. مدیریت کاربران: فعال/غیرفعال، ویرایش، حذف، ساخت مدیر/معاون
24. بازنشانی رمز هر کاربر (نمایش یک‌بار)
25. گزارش فعالیت‌ها (Audit log) با جستجو و فیلتر
26. نرمال‌سازی ورودی (ارقام فارسی/عربی، «ي/ك»)
